# Neutral project marks

These SVGs are landscape-specific fallback marks for repositories that do not publish a project-owned logo. They are not the authors' personal profile images and are not presented as official upstream brand assets.

- `avengerspro.svg`: abstract performance-efficiency routing paths forming an A.
- `irt-router.svg`: item-response curve with model and query points.
- `carrot.svg`: cost-aware route branching from a carrot symbol.
- `routerdc.svg`: paired contrastive embedding spaces and a selected route.
- `mmr-bench.svg`: multimodal inputs converging on a benchmark route.
- `tsrouter.svg`: time-series signals branching across modality and model paths.
- `acrouter.svg`: context-action-feedback loop around an agentic routing decision.
- `mtrouter.svg`: conversation history flowing into a multi-turn routing decision.

If an upstream project later publishes an official mark, replace the fallback and update `scripts/fetch-logos.sh` to use the upstream asset.
